Virginia is building its own online service where you can file your state income tax return for free, directly with the state. The new law tells the state's Tax Commissioner to offer filing "without monetary charge" for tax year 2028, so eligible taxpayers can first use it when they file in 2029.

The rules for who can use it must be looser than those of the IRS Direct File program in 2025. The IRS has since ended Direct File. The state has to consider Direct File's public code when it designs the system, learn from other states that have built free filing, and keep the system compatible with any free federal filing tool that comes later. The law removes the old rule that kept the state from competing with Virginia's vendor-run Free File program and repeals the 2010 law behind that arrangement; it does not guarantee that the vendor-run option will continue.

Del. Kimberly Pope Adams carried the House bill, and Sen. Jeremy McPike carried the identical Senate bill. Both passed the General Assembly without a single no vote. Gov. Abigail Spanberger signed them on March 31, 2026, and the law took effect that July.
