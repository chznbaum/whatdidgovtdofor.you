When Camden County declares a Code Red for dangerous heat, cooling centers open where anyone can get out of the heat. This contract pays for them. On June 18, 2026, the county Board of Commissioners approved a $136,761 contract award to several providers to run the centers, give support on site, and do outreach to people at risk, including people who are homeless or living in unsafe conditions. The county chose the providers through a publicly advertised request for proposals.

On Code Red days, sites listed by the state include Joseph's House, which is open around the clock, as well as the Wiggins School, New Beginnings and several county library branches. Call 2-1-1 for more information.

Camden is one of five counties in New Jersey's Code Red pilot program, along with Essex, Hudson, Mercer and Monmouth. The contract's funding depended on the board passing a separate budget resolution to add the money. Commissioner Louis Cappelli Jr., the board's director, led the board when every commissioner present voted to approve it.
